# getimagepress
Free image tools - Convert HEIC, WebP, SVG, JPG, PNG and compress images to target sizes


## Content readiness checks
Run `npm run build` before publishing. It regenerates HTML and FAQ structured data from scripts/build-pages.js, builds CSS, and runs `npm run test:readiness`. The production Docker build runs the same gate. Edit the generator rather than generated HTML. The tests protect AdSense ownership metadata and known misleading size/format claims; they are not a guarantee of AdSense approval.
